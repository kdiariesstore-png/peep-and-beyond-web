# عالم بيب وأصدقائه — Peep & Friends World

لعبة ويب للأطفال من ٣ إلى ٧ سنوات، بالعربية والإنجليزية. هذه **النسخة الأولى القابلة للعب**.
A web game for ages 3–7 in Arabic and English. This is the **first playable version**.

> هذا المجلد خارج `app/` و`public/`، فلا يُنشر مع الموقع. اللعبة محفوظة هنا فقط ولا تظهر للزوار.
> This folder sits outside `app/` and `public/`, so the website does not serve it.

## التشغيل محليًا / Run locally

```bash
cd game
python3 -m http.server 8080   # أو: npx serve .
```

ثم افتح `http://localhost:8080` بوضع أفقي. / Then open `http://localhost:8080` in landscape.

## المحتوى / What's inside

| الملف | الدور |
|---|---|
| `index.html` | الصفحة والأنماط (منصة ثابتة 1600×900 تتكيّف مع الشاشة) |
| `core.js` | الحفظ، اللغة، الصوت، أصوات الشخصيات، السحب واللمس، الانتقال بين المشاهد |
| `art.js` | الخلفيات، الأيقونات، الزينة، أغراض كوكو، البذور والنباتات |
| `scenes.js` | البداية، الخريطة، حديقة بيب، الهدايا، مسرح فيفي |
| `activities.js` | حديقة لولو، ورشة بامبو (بازل، طرق، بناء)، مغامرات كوكو |
| `parents.js` | بوابة الأهل والإعدادات |
| `assets/bg` | الخلفيات المرسومة (1600×900) |
| `assets/chars` | بيب (وقوف، مشي، قفز، فرح، جلوس، تلويح) والأصدقاء (وقوف، فرح، كلام) |
| `assets/pack` | الزينة، أغراض كوكو، البذور والنباتات، قطع البناء والطرق |
| `assets/puzzle`, `assets/story` | صور البازل وصفحات قصة «الديناصور بيب — قفزة السعادة» |

## ما زال تجريبيًا / Still a prototype

- **الشراء والاشتراك محاكاة.** لا يوجد دفع حقيقي، ولا يُعتبر جاهزًا قبل ربطه بمتجر Apple/Google واختباره.
- **صفحات القصة مدفوعة.** `assets/story` تحتوي صفحات الكتاب كاملة؛ لا تُنشر اللعبة للعامة قبل أن تُخدم هذه الصفحات خلف تحقّق شراء حقيقي.
- **الأصوات من صوت الجهاز** (Text-to-Speech) مؤقتًا، إلى أن تُسجَّل أصوات الشخصيات.
- **فيلم القصة قيد الإنتاج**؛ المتاح «اسمع واقرأ» بصفحات الكتاب.
- **الحفظ على الجهاز فقط** (`localStorage`)، دون حساب أو مزامنة.

الصور الأصلية عالية الدقة (PNG) غير محفوظة هنا لكبر حجمها؛ الموجود نسخ WebP مضغوطة للعبة.
